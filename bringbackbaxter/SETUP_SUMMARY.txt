================================================================================
KEY DIFFERENCES: OLD vs NEW
================================================================================

OLD SCRIPT (keyboard_ee_teleop.py + MoveIt):
  ✗ Blocks on each keypress while planner runs (1-2 seconds)
  ✗ Stop-start motion (jerky joints)
  ✗ ~15% velocity scaling (conservative)
  ✗ ROS 1 APIs (roscpp_initialize, moveit_commander)
  ✗ Not suitable for continuous control (teleop, VR)

NEW SCRIPT (diff_ik_teleop.py + frax):
  ✓ Streams at 100 Hz (10 ms latency)
  ✓ Smooth ramping velocity (hold keys for acceleration)
  ✓ Full joint speed available (damped IK for stability)
  ✓ Pure ROS 2 implementation (rclpy, ros2_control)
  ✓ Designed for continuous streaming control
  ✓ JAX autodiff available for future optimization

MATH:
  OLD: MoveIt trajectory planning (complex, many constraints)
  NEW: Damped least-squares differential IK (one line of math per cycle)
       dq = J^T (J J^T + λ²I)^-1 v_ee
       Microseconds per cycle via JAX JIT

================================================================================
ARCHITECTURE
================================================================================

Keyboard → Cartesian Velocity (twist) → Differential IK → Joint Velocity
                                              ↓
                                         JAX JIT (μs)
                                              ↓
                                         Joint Command
                                              ↓
                                  ros2_control JointTrajectoryController
                                              ↓
                                          Baxter Arm

Data Flow:
  Subscribe:  /robot/joint_states (sensor_msgs/JointState)
  Publish:    /right_arm_controller/follow_trajectory (trajectory_msgs/JointTrajectory)

================================================================================
TROUBLESHOOTING: QUICK REFERENCE
================================================================================

"ModuleNotFoundError: No module named 'frax'"
  → Use wrapper script: bash run_diff_ik_teleop.sh
  → Or activate venv: source ros2_ws/.venv/bin/activate

"Joint X not found in state"
  → Check /robot/joint_states being published
  → Verify controller is running: ros2 control list_controllers

Arm doesn't move
  → Confirm right_arm_controller is active
  → Check topic: ros2 topic echo /right_arm_controller/follow_trajectory

Motion is jerky
  → Increase damping: self.damping = 0.1
  → Reduce max velocity: self.max_dq = 0.2

Too slow to respond
  → Decrease damping: self.damping = 0.02
  → Increase keyboard sensitivity: v_step = 0.02

(See DIFFERENTIAL_IK_TELEOP.md for full debugging guide)
